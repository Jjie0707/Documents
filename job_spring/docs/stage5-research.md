# 阶段 5 补充：完整岗位字段、跨设备上传与免费视觉模型

2026-10-27，用户提出新增岗位字段需要补齐、区分 Windows/macOS/iOS/Android 上传体验、优先查找免费模型。本轮只做规划与官方资料核查，未实现业务、未改表、未提交/推送 Git，没有模型识别实测或真实图片外传。

## 1. 补齐原有新增和编辑流程

已核对 JobApplication、JobResponse、既有 SQL：公司/岗位名/城市/薪资/职责/要求/学历/来源平台/原始链接/截止日期均已有字段；写入 DTO/Service 和新增/编辑页尚只开放前四项。

5.1 增加职责/要求，5.2 增加学历/来源平台/原始链接/截止日期，均贯通新增、编辑、保存、回读和详情。公司、岗位名仍必填，其余选填；已有记录保留，不自动补造信息。

手动填写和图片识别使用同一套表单字段及岗位保存校验。图片里没有招聘链接时留空，由用户补充；不能依据公司名拼一个 URL。没有确定日期/来源/学历也留空，不猜测。是否需要截止日期等校验边界，按具体任务说明确定。

## 2. 同一网页，按浏览器能力适配入口

基础能力：标准 file input 选择本地图片，浏览器负责系统文件选择界面；其具体界面随系统和浏览器变化。accept 只是选择提示，服务端仍必须校验真实文件内容。[MDN file input](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/file)

| 平台 | 基础入口 | 增强入口与主要验收 |
| --- | --- | --- |
| Windows，优先 Edge/Chrome | 选择图片文件 | 拖拽、Ctrl+V 主动粘贴含图片的剪贴板；校验 PNG/JPEG、取消选择和重复选择。 |
| macOS，优先 Safari/Chrome | 选择图片文件 | 拖拽、Command+V 主动粘贴图片；剪贴板确有图片时才导入，保留文件选择回退。 |
| iOS，优先 Safari | 系统选图入口，从相册/文件选择 | 支持时提供拍照入口；验证截图、真实拍照结果、方向、格式与尺寸边界，取消/拒绝后可继续选图。 |
| Android，优先 Chrome | 系统选图入口，从相册/文件选择 | 支持时提供拍照入口，验证权限/取消、长截图、超大图及图片方向；具体选择器由设备决定。 |

拖拽采用 File API；粘贴从用户主动 paste 事件取图片，不后台读取整个剪贴板。[MDN File API](https://developer.mozilla.org/en-US/docs/Web/API/File_API/Using_files_from_web_applications)、[MDN clipboardData](https://developer.mozilla.org/en-US/docs/Web/API/ClipboardEvent/clipboardData)

capture 相机提示并非所有主流浏览器都支持，不能承诺每个系统弹出完全一样的选项，也不强制拍照覆盖相册选择。[MDN capture](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/capture)

实施约定：

- 先支持单张 PNG/JPEG，后端最终确认格式、大小、像素和可解码性，不只信扩展名/MIME。其他实际格式不能简单改后缀伪装通过。
- 对可能出现的 HEIC/HEIF 单独验收。浏览器可可靠解码转换时可评估转换为 JPEG；不能转换则明确提示使用 PNG/JPEG，不先承诺全部兼容。是否引入额外转换依赖在 5.3c 决定。
- 原图方向、长截图清晰度与超大像素都纳入验收；不能为了上传成功把文字压缩到不可读。
- 四种入口统一变成待上传的图片，再走同一后端校验；上传入口的差异不改变认证、额度和识别规则。
- 窄屏模拟验证布局；真机才验证系统选择器、相机、剪贴板与真实格式。上述设备均为计划覆盖，不是已经实测通过。
- 上传组拆成 5.3a 基础、5.3b 电脑增强、5.3c 手机适配；当前共 10 个开发小任务加整体验收，见[总计划](stage5-plan.md)。

## 3. 免费模型核查（截至 2026-10-27）

本项目需要“可被 Java 后端调用、支持图片输入并输出文字/岗位字段”的视觉 API；聊天网页免费、只有文本模型免费或赠送一次性试用金，均不等于已经满足需求。

### 优先候选：智谱 GLM-4.6V-Flash

官方将其列为免费视觉模型，输入支持图片，推荐场景包含 OCR 信息提取；页面提供图片 URL、Base64 及 Java 调用示例。基于这些公开能力，优先把它作为招聘截图识别候选，不据此宣称中文岗位识别精度已通过实测。[官方模型文档](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.6v-flash)

免费仍需要平台账号及 API Key。官方示例中的密钥是调用前提，当前没有获取、查找用户私密配置或使用未知密钥。具体并发、可用额度、账号开通条件和输出 JSON 的稳定性须在账号与样例实测时核对；不承诺永久免费、无限量或无需注册。

### 可选备选：Gemini API 的免费层

Google 官方提供部分模型的免费输入/输出额度，定价页列出支持图片输入的免费项，实际模型和额度以接入时控制台为准。[官方定价](https://ai.google.dev/gemini-api/docs/pricing)

Google 有地区使用范围，当前官方支持地区名单未列中国大陆；因此若计划从中国大陆环境直接使用，不能把它当成已保证可用的默认方案。[官方地区名单](https://ai.google.dev/gemini-api/docs/available-regions)

### 后续验证顺序

1. 优先验证免费视觉 API；账号/凭证由用户在本机私密配置中设置，不粘贴到聊天、文档、前端或 Git。
2. 用虚构招聘截图小样本验证连接、字段提取、长截图效果、缺失字段留空和 JSON 校验，记录实际限流与失败表现。
3. 达标后再接入正式业务流程；免费候选效果/稳定性/额度不满足时，评估用户提供的视觉 API 配置，不自动切换收费服务。
4. 接入通过独立客户端封装，供应商调整不影响岗位 CRUD、上传入口和草稿确认保存流程。

本轮完成的是官方资料筛选与规划。没有 API 凭证下的推理结果、国内网络连通结论或四平台真机测试结果；本轮无需重新运行 Java 测试或前端构建。
